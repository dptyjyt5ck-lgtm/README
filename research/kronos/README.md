# Проверка Kronos на крипте

[Kronos](https://github.com/shiyu-coder/Kronos) — открытая нейросеть, обученная на свечах 45 бирж. Здесь проверяем один вопрос: **даёт ли её прогноз преимущество после комиссий Bybit**, по сравнению с двумя эталонами:
- **random-walk** — «рынок случаен», преимущества быть не должно;
- **momentum** — «последнее движение продолжится».

## Как устроена проверка

- Свечи H1 BTC, ETH, SOL с Bybit, по умолчанию **с 01.09.2025**: модель опубликована в августе 2025 и этих данных не видела.
- Каждые 12 часов модель получает 256 прошлых свечей и строит 8 вариантов пути на 12 часов вперёд.
- Отсюда считается доля путей выше текущей цены (`p_up`). Сделка: лонг, если `p_up ≥ порог`, шорт, если `p_up ≤ 1 − порог`, выход через 12 часов.
- Издержки: 7,5 б.п. на сторону (тейкер 0,055% + проскальзывание), то есть 0,15% на сделку.
- Порог подбирается на **первой половине** периода, а результат честно считается на **второй**, которую подбор не видел.

## Запуск (на своём компьютере)

```bash
git clone https://github.com/shiyu-coder/Kronos ~/Kronos
pip install torch einops huggingface_hub safetensors pandas requests
cd research/kronos
python run_kronos_check.py --kronos-path ~/Kronos
```

- Сначала можно проверить, что всё работает, без модели: `python run_kronos_check.py --baselines-only`.
- По умолчанию `--size mini` (4 млн параметров). На обычном процессоре это займёт примерно 1–2 часа (оценка). С видеокартой или в бесплатном Google Colab (GPU) можно взять `--size small` или `--size base`.
- Если запуск прервался, просто запустите снова: готовые прогнозы лежат в `preds/`.
- Результат: `REPORT_kronos.md` (таблица) и `results_kronos.json`.

## Как читать результат

| Показатель | Нет преимущества | Есть что-то |
|---|---|---|
| Угадано направлений | ~50% | устойчиво 53%+ |
| IC (корреляция прогноза с фактом) | ~0 | 0,03–0,05 и выше на всех монетах |
| Проверка: средний результат | ≤ 0 б.п. | > 0 после издержек |
| Проверка: t | < 2 | > 2 |

Одна хорошая цифра на одной монете — это ещё не преимущество. Даже momentum на чисто случайных данных в тесте стенда показал 59% угаданных направлений при t = 1,25, это шум. Подключать Kronos к ботам стоит, только если он лучше обоих эталонов на **второй половине** периода на большинстве монет.

Тесты стенда (без сети и torch): `python -m pytest -q research/kronos`
