# Бот «B1 Зигзаг» v1.30 (демо): что это и как запустить

Файл советника: `B1_Zigzag_v1_30.mq5`.

**Главное.** Эта версия только для **демо-счёта**: смотреть, как стратегия ведёт себя по месяцам.
Проверка на истории показала, что **устойчивой прибыли у стратегии пока нет** (в среднем около нуля).
На реальном счёте бот не запустится: увидит реальный счёт и остановится сам.

---

## Что изменилось по сравнению с 1.29

1. **Настоящие лимитные ордера.** Раньше бот ждал, когда цена дойдёт до уровня, и входил по рынку.
   Теперь он сразу ставит у брокера настоящие лимитки (BuyLimit / SellLimit) на уровнях
   0,618 / 0,5 / 0,382 / 0,236 / 0,14, к каждой сразу привязан общий стоп. Тейк-профита у ордеров нет:
   выход ведёт сам бот (за B, на цели 1,618, трейлинг, застой, время).
   - Лимитки стоят только у **одной** фигуры. Появилась новая фигура, а старая ещё ни разу не исполнилась —
     старые лимитки снимаются, ставятся новые.
   - Если по фигуре уже открыта позиция, её лимитки не трогаем, а новые фигуры ждут, пока позиция закроется.
   - Лимитки снимаются, когда цена ушла за B, когда позиция по фигуре закрылась, когда вышел срок
     (если включён `SetupMaxBars`).
   - В комментарии ордера видно, что это за уровень и фигура, например `B1 Z 0,618 #12`.
   - Если бот перезапустить, он снимает свои старые лимитки (пишет об этом в журнал) и выставляет их заново.
     Открытую позицию он находит и продолжает сопровождать.
2. **Новости.** За 15 минут до важной новости лимитки снимаются, через 15 минут после — ставятся снова
   (если цена за это время не прошла уровень). **Если файла новостей нет, бот не останавливается**:
   на графике и в журнале появится предупреждение «фильтр новостей ВЫКЛЮЧЕН», и он работает дальше.
3. **Потолок риска.** На маленьком счёте каждый уровень получает минимум 0,01 лота, поэтому риск бывает выше
   задуманного. Новый параметр `MaxRiskPercent` (по умолчанию 5 %): если риск выше, бот убирает уровни,
   начиная с самого дальнего от стопа (сначала 0,618). Если даже 0,01 лота на одном ближайшем уровне
   дороже потолка, фигура пропускается. В журнал пишется план риска и фактический риск в $ и в %.
4. **Исправления.** Объёмы округляются по шагу лота брокера, цены по шагу цены. У каждого уровня свой
   счётчик ошибок. Частичное закрытие на неттинге по-прежнему идёт встречной сделкой, но только когда
   лимиток уже нет, и никогда не больше позиции (позиция не «перевернётся»).
5. **Отчёт по месяцам.** Каждая закрытая сделка записывается строкой в файл
   `b1_zigzag_<символ>_trades.csv` (например `b1_zigzag_EURUSD_trades.csv`). В начале нового месяца
   в журнал пишется итог прошлого месяца, и он же виден на графике.
6. **Защита от реального счёта.** На реальном счёте бот не запускается, пока параметр `AllowRealAccount = false`.

## Параметры (что можно менять)

Менять стоит только первые строки таблицы. Остальное — правила стратегии, их лучше не трогать.

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `RiskPercent` | **3.0** | Риск на одну фигуру в % баланса, если исполнятся все 5 лимиток |
| `MaxRiskPercent` | **5.0** | Потолок риска на фигуру. Выше — бот убирает дальние уровни или пропускает фигуру |
| `UseNewsFilter` | true | Снимать лимитки на время важных новостей |
| `NewsFile` | b1_news_utc.csv | Файл новостей в папке Common\Files (нет файла — фильтр выключится сам) |
| `NewsWindowMin` | 15 | Сколько минут до и после новости лимиток нет |
| `MaxHoldDays` | 28 | Через сколько дней позиция закрывается в любом случае |
| `DrawObjects` | true | Рисовать на графике фигуры с входом (A, B, уровни, стоп, цель) |
| `Magic` | 260113 | «Номер» бота. Если ставите бота на 2 разных инструмента — можно оставить одинаковым |
| `AllowRealAccount` | false | Не трогать. false = на реальном счёте бот не запустится |
| `ExtremeHours` | 72 | A — самая крайняя цена за столько часов |
| `TrendMinATR` | 8.0 | До точки A был тренд не меньше 8 ATR |
| `ImpulseMinATR` | 2.0 | Импульс AB не меньше 2 ATR |
| `TrendBars` / `TrendEff` | 48 / 0.30 | Движение к A направленное, а не «пила» |
| `StopK` | 0.14 | Стоп на −0,14 сетки за точкой A |
| `Weight618` | 60 | 60 % объёма на 0,618, остальное поровну на 4 уровня |
| `TargetK` | 1.618 | Цель |
| `PartialAtB` | 25 | За B закрыть 25 % объёма и стоп в безубыток |
| `TargetPart` | 30 | На цели закрыть ещё 30 %, остаток ведёт трейлинг |
| `TrailATRMult` | 3.0 | Трейлинг: 3 × ATR |
| `StagBars`, `StagMinR`, `StagGiveBack`, `StagMinCurR` | 12, 0.7, 40, 0.2 | Выход из «застоя» после прибыли |
| `SetupMaxBars` | 0 | 0 = лимитки живут, пока цена не ушла за B |
| `ServerTimeMode`, `ServerGMTOffset` | 0, 2 | Время сервера для новостей |
| `HistoryBars` | 4000 | Сколько часовых свечей истории размечать при запуске |

**Про риск простыми словами.** При риске 3–5 % на фигуру серия из 10 убытков подряд съедает примерно
26–40 % депозита. Для демо это нормально, для настоящих денег — много.

## Как установить и запустить на ДЕМО-счёте

**С айфона бота запустить нельзя.** Приложение MT5 для iPhone не умеет запускать советников.
Нужен компьютер с Windows или VPS (удалённый компьютер в интернете, который работает круглосуточно):

- **Виртуальный хостинг MQL5** — встроен в MT5 на компьютере (правой кнопкой по счёту → «Зарегистрировать
  виртуальный сервер»), около 10–15 $ в месяц. Настраиваете один раз с компьютера, дальше бот работает сам.
- Или **любой Windows VPS**: заходите на него через удалённый рабочий стол (на айфоне тоже можно — приложение
  «Windows App» / Microsoft Remote Desktop) и ставите там MT5.

С айфона потом можно просто **смотреть** сделки в приложении MT5, войдя в тот же демо-счёт.

### Шаги (на компьютере или VPS)

1. Установите MetaTrader 5, откройте **демо-счёт** Just2Trade (неттинговый).
2. MT5 → меню **Файл → Открыть каталог данных** → папка `MQL5\Experts`. Положите туда `B1_Zigzag_v1_30.mq5`.
3. Откройте файл в MetaEditor (двойной щелчок) и нажмите **«Компилировать»** (F7). Ошибок быть не должно.
   Если есть — пришлите скриншот вкладки «Ошибки».
4. (По желанию) файл новостей `b1_news_utc.csv` положите в папку **Common\Files**
   (Файл → Открыть каталог данных → подняться на уровень выше → `Common\Files`). Без него бот тоже работает.
5. Откройте график нужного инструмента, например **EURUSD, H1**. **Один инструмент — один график с ботом.**
6. Перетащите бота на график. Вкладка «Общие»: галочка **«Разрешить алгоритмическую торговлю»**.
   Параметры можно оставить как есть.
7. Вверху MT5 включите кнопку **«Алго-трейдинг»** (должна быть зелёной).
8. В левом верхнем углу графика появится надпись **«B1 Зигзаг v1.30 (демо)»**, строка состояния
   (есть ли позиция, какие лимитки стоят) и итоги месяца.

**Не торгуйте вручную тем же инструментом на этом счёте**: на неттинговом счёте ваша и ботовская позиция сольются в одну.

Бот может днями ничего не делать — это нормально, хороших фигур немного.

## Как читать отчёт

Файл: `Common\Files\b1_zigzag_EURUSD_trades.csv` (в тестере — `..._tester_trades.csv`, он каждый прогон начинается заново).
Открывается в Excel или в «Numbers» на айфоне. Разделитель — точка с запятой.

| Колонка | Что значит |
|---|---|
| открытие / закрытие | Время первой исполненной лимитки и время полного закрытия |
| направление | покупка / продажа |
| уровни | Какие лимитки исполнились, например `0,618+0,5` |
| объём | Сколько лотов всего вошло |
| прибыль $ | Итог сделки с комиссией и свопом |
| прибыль R | Итог в «рисках»: −1 = потеряли запланированный риск, +2 = заработали два риска |
| баланс после | Баланс счёта после закрытия |
| причина выхода | стоп / стоп в безубытке / трейлинг-стоп / застой / время / закрыто вручную |

Итог месяца в журнале (вкладка «Эксперты») выглядит так:
`===== ИТОГ МЕСЯЦА ===== Прошлый месяц (10.2026): сделок 4, прибыль 23.10 $ (+2.3%), прибыльных 2 из 4 (50%)`

---

## Что прислать через месяц

1. Файл `b1_zigzag_<символ>_trades.csv` из папки Common\Files.
2. Строку «ИТОГ МЕСЯЦА» из журнала (или скриншот графика с надписью в углу).
3. Если что-то было странно — журнал за этот день: вкладка «Эксперты», правой кнопкой → «Открыть»
   (это текстовые файлы по датам).
4. Скриншот вкладки «Торговля» / «История», если были ошибки ордеров.

По 4–5 сделкам за месяц выводы делать рано: смотрим минимум 3 месяца и несколько инструментов.
